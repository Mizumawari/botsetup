# 位置タイムライン（location-timeline）

「いつ・どこにいたか」を日ごとに振り返るための記録アプリのソースコードです。常駐エージェント（Muse）が持ち主の依頼で作った Web アプリ（TypeScript スペース：React クライアント＋サーバアクション＋SQLite/Drizzle）を、そのまま公開用に切り出したものです。

**記録データそのものは含みません。** 位置の記録・写真・メモはアプリ側のデータベースにあり、このフォルダにあるのは「アプリの作り」だけです。

## できること

- 日表示：その日の滞在（場所・到着〜出発・滞在時間）と移動（手段・距離）を縦タイムラインで表示。滞在に届かない短い記録も「確定前」としてその時刻に出す
- 月カレンダーと「月のまとめ」：総移動距離、記録日数、よく行った場所、初めて行った場所、移動手段の内訳、日ごとの一覧
- 滞在への写真登録（複数枚、サムネイル＋拡大表示）と、写真だけを月ごとに並べるアルバム表示
- 一言メモ：その日全体への一言と、滞在ごとの一言（座標に紐づくので、滞在が再計算されても消えない）
- 名前つき場所：「自宅」「実家」などを座標に登録し、近くの滞在へ自動で名前を伝播
- 過去分の取り込み：Google マップのタイムライン書き出し JSON（端末内エクスポート／旧 Takeout の形式）を取り込み、滞在・移動・位置ポイントとして表示。取り込み履歴からの取り消しも可能
- 今日からの自動記録：ペアリングしたスマートフォンの位置を1時間ごとに取り込んで自動で貯める（スケジュールはアプリ側で管理）

## 構成

- `client/src/` — React クライアント（日表示、カレンダー、月のまとめ、アルバム、取り込みパーサ `importParser.ts`、地図ヘルパ）
- `server/src/actions.ts` — サーバアクション（日・月の取得、滞在の自動整理、写真・メモ、取り込み）
- `server/src/schema.ts` / `drizzle/` — スキーマとマイグレーション
- `server/src/privileged.ts` — ホスト側ハンドラ（ワークスペースに置かれた書き出しファイルを読むための特権経路）

## この環境固有の部分（移植時の注意）

- `@hatch/space-sdk` は Muse の Web アプリ実行基盤専用の SDK です。他の環境で動かす場合は、アクション呼び出しと特権ハンドラの部分を置き換えてください
- 過去分の自動取り込みは、書き出しファイルを置くワークスペース内の固定パス（`~/workspace/location-timeline/inbox/`）を前提にしています
- スマートフォンの位置の定期取り込みは、エージェント側のスケジュール実行と端末連携が前提です

## 設計メモ

- 滞在の確定は「同じ場所に10分以上」を目安にしつつ、確定に届かない記録も落とさず暫定表示する（記録を残すことが目的なので、判定を厳しくしすぎない）
- 写真とメモは滞在の ID ではなく「日付＋座標」に紐づける。再計算で滞在が作り直されても紐づけが残り、どこにも付かなかった分は「この日の写真／メモ」として別枠に出す
- 取り込みは冪等にする（同じファイルを再実行しても二重に入らない）
