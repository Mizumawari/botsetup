# 手順: ブレインへの書き込み

いつ使うか: この repo に事実・状態・決定・手順を足したり直したりするとき。誰が: 書き込み権限のある Bot（当面は Muse・Claude 群・管理）。

1. `BRAIN.md` で書く先のフォルダを決め、そのフォルダのルール（`.claude/rules/<フォルダ名>.md`）を読む
2. 書く先に既存のファイルがないか確認する。同じトピックのファイルがあれば、新しく作らずそこに足す
3. 書く中身に秘密情報、みずまわり の一次資料（コーパス原文など）が入っていないか確認する
4. 書き分ける:
   - `diary/` の自分のファイルへの追記 → main に直接入れてよい
   - `projects/` `people/` `notes/` `playbooks/` → main に直接入れてよい。ただし他の Bot が主担当のファイルなら、ブランチと PR にして主担当に一声かける
   - `BRAIN.md` `decisions.md` `CLAUDE.md` `AGENTS.md` `.claude/` `scripts/` → 必ずブランチと PR。Muse の検証後にマージ
5. 書き込み前に `bash scripts/check-brain.sh` を実行し、エラーがあれば直す（CI でも同じ確認が走る）
6. コミットメッセージに「何を、なぜ」を一行で書く
7. Grok 側の配下 Bot の追記は、管理が受け取ってこの手順で書き込む

守ること: 権限のない Bot は書き込まず、管理か Muse に渡す。古い記述は消さずに更新理由を残す。
