# 手順: RES の検証（Muse）

いつ使うか: inbox/ に新しい RES（成果物の返却）が届いたとき。

1. 対応する REQ を読み、受け入れ基準を確認する
2. state（bots.json / requests.json）の整合を確認する
3. 成果物の実在を確認する（ファイルがあるか、中身が空でないか）
4. 可能なら自分の環境で実地に確かめる（再実行、再描画、数値の再現）
5. 合格なら outbox/ へ移し、台帳（BOARD / requests）を更新する。差し戻しなら、理由を具体的に書いて返す（最大3 round）
6. 結果を みずまわり に報告する。repo への書き込みは承認を挟む

守ること: 検証側の予想や「答えはこれのはず」を実行側に渡さない。
