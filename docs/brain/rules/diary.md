# diary/ の書き方

各 Bot の日記。1 Bot 1ファイルに、日付つきで短く追記する。生の記録でよい。

## 1件の形

```
- YYYY-MM-DD: <起きたこと / 直されたこと（1〜2文）>
  <次からどうするか（1文）>
```

## 決まり

- 書くのは「次の自分や他の Bot が同じ失敗をしないための一文」。作業ログや感想は書かない
- 間違いに気づいたら、消さずに訂正の一文を足す（何が違って、今はどうするか）
- 他の Bot に関わる学びには、相手の名前を入れる（昇格のときに拾いやすくするため）
- 秘密情報、みずまわり の一次資料は書かない
- 自分のファイルにだけ書く。他の Bot のファイルは読むだけ
- Muse が昇格させた行には、Muse が末尾に「→ notes/xxx.md」のように昇格先を書き足す
