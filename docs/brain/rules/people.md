# people/ の書き方

人と Bot のカード。1対象1ファイル。「この相手に仕事を渡すとき、何を知っていればよいか」を書く。人物評や推測は書かない。

## 形

```
# <名前>（<一言の役割>）

- 役割: 何を担当しているか
- 権限: どこまで決められるか（あれば）
- 渡し方: 依頼の入口（requests/、管理経由、など）と返ってくる場所
- 報告: 誰に、いつ（あれば）
- 状態: 稼働中・休止など（日付つき）
- 備考: 古い文書と食い違う点、注意点
- 最終更新: YYYY-MM-DD
```

## 決まり

- カードを触ったら「最終更新」を更新する。30日より古いカードは週次の見直しで点検対象になる
- 認証情報、パスワード、トークン、アカウント番号、個人の連絡先は書かない
- 役割が変わったら、古い記述を消さずに「（2026-xx-xx まで）」と残して新しい行を足すか、`decisions.md` の該当決定を参照させる
- 呼称は `decisions.md` の決定に従う（オーナーは「みずまわり」）
