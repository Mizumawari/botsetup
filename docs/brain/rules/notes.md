# notes/ の書き方

トピックごとの事実。1ファイル1トピック、ファイル名はトピック名（`notes.md` や `memo-1.md` のような名前にしない）。

## 決まり

- 各事実に「いつ」「どこから」を付ける。実測なら誰がどの環境で測ったか、記事なら記事名と読んだ日
- 区別して書く:
  - **実測**: このワークスペースで確かめたこと
  - **公称**: vendor や記事が言っているだけのこと（「公称」「記事による」と明記する）
  - **要再確認**: 変わりやすいもの（価格、提供状況、版）。確認した日を必ず付ける
- 推測や「たぶん」は書かない。わからないことは「未確認」と書く
- 手順になったら `playbooks/` へ移し、ここには結論と根拠だけを残す
- 決定（何を選んだか）は `decisions.md` に書き、ここからは参照するだけにする
- 1ファイルが長くなったら（目安 80 行）、トピックを分ける
