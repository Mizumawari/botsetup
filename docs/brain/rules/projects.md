# projects/ の書き方

1プロジェクト1ファイル。「いま何が起きていて、次は何か」を書く場所。経緯の長話は書かない（決定は `decisions.md`、事実は `notes/`）。

## 形

```
# <プロジェクト名>

<一行で何のためのものか>

## 状態（YYYY-MM-DD）
- 動いているもの、止まっているもの、その理由

## 次にやること
- 次の一手（担当が決まっていれば担当も）

## 止まっているところ（あれば）
- 何待ちか（誰の判断・どの REQ）
```

## 決まり

- 「状態」の見出しの日付を、書き換えるたびに更新する。日付が14日より古いファイルは週次の見直しで点検対象になる
- REQ 番号、担当、待ち先（みずまわり の判断待ち、など）は具体的に書く。曖昧な「調整中」は書かない
- 終わったことは「状態」から消して、必要なら `decisions.md` に結果を一行残す
- `now.md` は全プロジェクトの最優先だけを1行ずつ。各行は該当プロジェクトのファイルと矛盾させない。
  `now.md` は Claude 系 Bot に毎回読み込まれるので、15行以内に保つ
- 別 repo のプロジェクトは repo 名を書く（例: 別 repo の名前）
