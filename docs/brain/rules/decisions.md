# decisions.md の書き方

決定の記録。新しい日付が上に来るように追記する。過去の決定は書き換えない。

## 形

```
## YYYY-MM-DD

- **<何を決めたか（短く）>**: 中身。
  理由: なぜそう決めたか。
  決めた人: みずまわり / Muse など。関連: REQ 番号や関係ファイル
```

## 決まり

- 変更は Muse の検証後に確定する（RULES §3）。権限のある Bot でも、直接 main に入れずブランチと PR で出す
- 古い決定を覆すときは、新しい日付の下に「<旧決定> を取り消し」と書き、理由を添える。古い行は消さない
- 決定ではないもの（事実、状態、手順）はここに書かない
- みずまわり の承認待ちのものは決定ではない。決まるまで `projects/` の「止まっているところ」に置く
